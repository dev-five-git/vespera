# Changelog

Release notes for every published package (the `vespera*` crates on
crates.io and `kr.devfive:vespera-bridge` / the Gradle plugin on Maven
Central) are generated by [changepacks](https://github.com/changepacks) from
the `.changepacks/changepack_log_*.json` entries merged into `main`, and are
published on the
[GitHub Releases](https://github.com/dev-five-git/vespera/releases) page.
This file only summarises breaking changes that need migration work; see the
[migration guide](https://vespera.devfive.kr/documentation/migration) for
details.

## 0.6.0 (unreleased)

A hardening release. Every item below can change behaviour or break the build
of an existing 0.5 application.

### OpenAPI (`vespera`, `vespera_macro`, `vespera_core`)

- Untagged enums emit `anyOf` instead of `oneOf`.
- Tuple / newtype structs, arrays and tuples get real array / inner schemas;
  `skip_serializing` / `skip_serializing_if` fields are no longer `required`.
- Internally tagged newtype variants, variant `skip` / `other` and
  `Arc` / `Rc` / `Cow` / `NonZero*` are supported; plain tuple returns and
  body-less `error_status` codes are documented.
- Colliding default `operationId`s are module-qualified.
- New compile errors: duplicate explicit `operation_id`s, unknown security
  schemes (checked after `merge`), malformed `#[schema(...)]`, and scalar
  payloads in internally tagged newtype variants.
- Known `headers::*` `TypedHeader` parameters use the real header name.

### `Validated<T>`

- `Json` / `Form` / `Query` / `Path` deserialization failures now return
  `422` with the `{"errors":[{"path","message"}]}` envelope instead of axum's
  plain-text rejection.

### In-process / JNI (`vespera_inprocess`, `vespera_jni`)

- `SYNC` / `DIRECT` dispatch runs on the shared Tokio runtime (no per-thread
  runtimes); its blocking pool is capped at 512 threads by default.
- Default limits: 64 MiB buffered request (`413`), 256 MiB buffered response
  (`500`), 4096 in-flight `dispatchAsync` calls (`503`); optional dispatch
  timeout (`504`) and streamed-request cap. Set a limit to `0` to disable it.
- Streaming dispatch hoists `422` validation errors and reports failures after
  the first body byte as `IOException` instead of a synthetic `500`.

### Java bridge (`kr.devfive:vespera-bridge`)

- Spring is a provided dependency (Spring Boot 3.5 and 4 supported); declare
  `spring-boot-starter-web` / `jackson-databind` yourself.
- `HEAD` responses keep the real `Content-Length`.
- The native library is extracted per user, permission-checked and
  content-addressed (`vespera.native.dir` / `VESPERA_NATIVE_DIR`).
- New `vespera.bridge.native.*` properties; the new `configure*` methods return
  `boolean`.
- The bridge JAR and the native library must come from the same release.
- Gradle plugin: `publishPlugins` fails without Plugin Portal credentials.

### Java bridge hardening (`kr.devfive:vespera-bridge`, Gradle plugin)

Behaviour changes — no code change is needed, but they are observable:

- An oversized `SYNC` / `ASYNC` response answers `500` instead of `413`, and
  `vespera.bridge.max-buffered-response-bytes` (default 64 MiB) is forwarded to
  the native buffered-response cap unless that cap is set explicitly.
- CORS preflights are routed to the Rust router by default
  (`vespera.bridge.cors=rust`); set `vespera.bridge.cors=spring` to keep Spring
  MVC's preflight handling. Duplicate `Access-Control-*` headers are resolved in
  favour of the configured owner.
- Unexpected proxy errors answer the fixed body `vespera dispatch failed`
  (details only in the WARN log), and writing a proxy error keeps headers set by
  servlet filters.
- `DispatchEvent.app()`, the `app` metric tag and the WARN log report `UNKNOWN`
  for client-selected app names not known to be registered.
- A missing native library answers `503` instead of throwing
  `UnsatisfiedLinkError`; a new `vespera` Actuator health indicator reports it.
- `VesperaBridge.init` fails when the native library's `major.minor` differs
  from the bridge's (`-Dvespera.native.versionCheck=warn|off`); this needs a
  native library exporting `nativeVersion0` (older ones only log a warning).
- On Windows, an extraction directory that is not owned by the current user or
  whose ACL lets other principals write is replaced by a fresh random one.
- `proxy(...)` returns a `DeferredResult` for `ASYNC`.
- Gradle plugin: hyphenated `crateName`s work (new `packageName` / `libName`),
  `bridgeVersion` defaults to the matching bridge release, `cargoSourceRoots` is
  ignored and `CargoBuildTask.commands` was replaced by its properties.
